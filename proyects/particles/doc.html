ParticleLab v9 documentación

Sistema de partículas ECS con pool pre-asignado, sprites pre-renderizados, 6 tipos de efectos, 3 capas independientes, 71 presets, 20 multi-presets y autoescalado de rendimiento.

Introducción

ParticleLab es una librería de partículas basada en arquitectura ECS (Entity-Component-System) orientada a cero allocs en runtime. Se compone de dos archivos:

  • particle.js — el motor (expone window.ParticleLab)
  • index.html — tu página con un <canvas>

Características principales:

  • pool fijo Pool pre-asignado de partículas (por defecto 2000, configurable). Lista densa de vivos + freeList. Sin GC churn en emisión.
  • sprites 11 tipos × 21 colores = 231 sprites pre-renderizados con 3 niveles de detalle (32 / 64 / 128 px). drawImage puro en el bucle.
  • 3 capas Tres capas independientes, cada una con su propio effectType, behavior y parámetros.
  • 6 efectos particle, bolt, centella, ballLightning, tesla, chain.
  • 3 comportamientos free, boid (flocking con spatial hash), rigid (colisiones entre partículas).
  • 71 presets Electricidad, fuego, agua, vida, espacio, acción, físicas, degradados, boids, chains, rigid, trails, metaballs, curl noise, flow field, parallax.
  • 20 multi-presets Combinaciones de 3 capas listas para usar.
  • LOD automático Simplifica trigonometría, salta wobble/flicker y baja la resolución de render si el FPS cae.
  • FAST_TRIG Tablas de sin/cos/tan/atan precomputadas que se activan automáticamente en mobile.

Instalación

Descargá particle.js y creá tu HTML. No necesita build, ni npm install, ni transpiladores.

<!-- index.html -->
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <style>
    html, body { margin: 0; height: 100%; background: #05060a; overflow: hidden; }
    #game { display: block; width: 100vw; height: 100vh; }
  </style>
</head>
<body>
  <canvas id="game"></canvas>
  <script src="particle.js"></script>
  <script>
    // tu código acá
  </script>
</body>
</html>
Nota particle.js se autoinstala en window.ParticleLab. También exporta module.exports si lo usás en Node con un canvas polyfill.

Quick Start

El ejemplo mínimo: crear, aplicar un preset, arrancar.

const canvas = document.getElementById('game');
const lab = ParticleLab.create(canvas, { poolSize: 3000 });

lab.applyMultiPreset('storm'); // o applyPreset('fire', 0)
lab.start();

Eso ya renderiza una tormenta con 3 capas (lluvia + hojas + rayos).

Recomendado Llamá lab.spawnAt(x, y, count) en pointerdown / pointermove para hacer estallar partículas donde el usuario toca o hace clic.

Capas (Layers)

Cada instancia tiene 3 capas independientes en lab.layers[0..2]. Cada capa es un objeto plano con ~80 campos. Se puede editar en vivo:

lab.layers[0].rate = 300;
lab.layers[0].colors = ['magic', 'spark'];
lab.layers[1].gravityY = 500;

effectType — 6 tipos

Cada capa puede emitir un tipo distinto. Cambiar effectType redefine qué sistema procesa y cómo se renderiza la capa.

particle
Partícula clásica ECS. Usa pool, física, curvas, blend, trail, metaball, spawnOnDeath. Es el modo por defecto.
bolt ⚡
Rayos por midpoint displacement + ramas recursivas. Se añaden a world.bolts. Dispara screenFlash.
centella ✦
Estrella de rayos cortos. Flash central + N rayos radiales. Se añaden a world.bolts.
ballLightning 🔮
Orbe globular errático con arcos eléctricos. Se añade a world.orbs. Al morir explota.
tesla ⚙
Bobina de Tesla: dos electrodos fijos entre los que saltan arcos. Se añade a world.teslas.
chain 🔗
Cadena Verlet con N puntos. Extremo superior anclado al emitter. Se añade a world.chains.

behavior — 3 comportamientos

Solo aplica a effectType: 'particle'. Determina qué sistema mueve las partículas.

ValorDescripciónPresets
freeFísica clásica por partícula (gravedad, drag, swirl, curl, flow...).casi todos
boidFlocking con spatial hash de 100 px. Cohesión + alineación + separación. Se salta motionSystem.boidBirds, boidFish, boidFireflies
rigidCuerpos rígidos 2D con colisiones por impulso. Usa world.rigidHash.rigidDebris, rigidCoins

FAST_TRIG

Sistema de tablas trigonométricas precomputadas que se activa automáticamente en mobile para ahorrar ciclos de CPU.

Estado global

CampoDefaultDescripción
ParticleLab.FAST_TRIG.mode'auto''auto' = activo solo en mobile. 'on' = siempre. 'off' = nunca.
ParticleLab.FAST_TRIG.precision2360 × precision entradas. 1=360°, 2=720°, 4=1440°. Más precisión = más RAM.
ParticleLab.FAST_TRIG.enabledautoSe recalcula con updateTrigEnabled().
ParticleLab.FAST_TRIG.ramKB~14RAM usada por las tablas.

Configurar

// Forzar activación en desktop
ParticleLab.FAST_TRIG.mode = 'on';
ParticleLab.updateTrigEnabled();

// Cambiar precisión (regenera tablas)
ParticleLab.FAST_TRIG.precision = 4;
ParticleLab.applyTrigPrecision();

Usar en tu código

const { fsin, fcos, fatan2 } = ParticleLab;
const angle = fatan2(dy, dx);
const vx = fcos(angle) * speed;
const vy = fsin(angle) * speed;

Rendimiento / LOD

LOD automático (3 niveles)

Se recalcula cada frame según el número de partículas vivas:

LODTriggerQué desactiva
0< 3000 vivasNada. Calidad máxima.
13000 – 6000Sin trails ribbon.
2> 6000Sin trails, sin wobble, sin flicker, sin gradiente de color, sin rotación. Physics cada 2 frames con dt×2.

Podés forzar el LOD con lab.world.lodRequested = 0 | 1 | 2 (-1 = auto).

Auto render scale

Cuando autoRenderScale está activo, cada segundo evalúa el frame time promedio:

  • > 17 ms (menos de ~59 fps) → baja renderScale en 0.05 (mín. 0.5)
  • < 13 ms (más de ~77 fps) → sube renderScale en 0.05 (máx. 1.0)

Reducir la resolución del canvas offscreen baja drásticamente el costo de rasterizado sin afectar la cantidad de partículas.

Recomendaciones

  • Pool de 2000–3000 es suficiente para la mayoría de escenas.
  • Usá blend: 'source-over' cuando puedas; lighter es más caro.
  • Evitá trail: true en más de una capa simultáneamente.
  • Para explosiones grandes, usá spawnOnDeath con count moderado (20–40).
  • En mobile, dejá dprMode: 'auto' (fuerza DPR 1) y autoRenderScale: true.

Ejemplos

Tormenta con spawn al tocar

const lab = ParticleLab.create(canvas, { poolSize: 3000 });
lab.applyMultiPreset('storm');
lab.start();

canvas.addEventListener('pointerdown', e => {
  lab.spawnAt(e.clientX, e.clientY, 40);
});

Slow-motion con bloom

lab.setTimeScale(0.3);
lab.setBloom(0.8);
lab.setTrail(0.1);   // estela larga

Editar capa en vivo

const L = lab.layers[0];
L.colors = ['magic', 'plasma'];
L.gravityY = 200;
L.swirl = 4;
L.blend = 'lighter';

Cohete que explota en chispas (3 niveles)

lab.applyPreset('rocketLaunch', 0);
// rocketLaunch → firework → (nada, firework no tiene spawnOnDeath)
// Para cadena de 3 niveles:
lab.applyPreset('inheritRocket', 0);

Boids + estela al tocar

lab.applyPreset('boidBirds', 0);
lab.setLayerEnabled(1, false);
lab.setLayerEnabled(2, false);

canvas.addEventListener('pointermove', e => {
  lab.layers[0].emitter.fx = e.clientX / innerWidth;
  lab.layers[0].emitter.fy = e.clientY / innerHeight;
});

Loop manual (sin start)

let last = performance.now();
function tick(t) {
  const dt = Math.min((t - last) / 1000, 0.05);
  last = t;
  lab.update(dt);
  lab.render();
  requestAnimationFrame(tick);
}
requestAnimationFrame(tick);

Escuchar el frame

lab.onFrame = (dt) => {
  // dt en segundos
  hud.textContent = `${lab.world.activeCount} partículas`;
};
Fin particle.js expone también lab.world si necesitás acceso de bajo nivel a ECS (components por id, aliveList, freeList, etc.). La mayoría de los casos no lo requiere: con applyPreset, applyMultiPreset, spawnAt y editar lab.layers[i] alcanza.
