// FEATURES

Todo lo que necesitás.
Nada que no.

ParticleLab es un motor de partículas minimalista pero completo. Arquitectura ECS con pool pre-asignado, sprites pre-renderizados, LOD automático y cero allocs en runtime.

⚡

ECS puro

Entidades, componentes en Maps y sistemas. Pool de 3000 partículas con zero GC churn. Lista densa de vivos + freeList.

🎨

Sprites pre-renderizados

11 tipos × 21 colores = 231 sprites generados al cargar. 3 niveles de detalle (32 / 64 / 128 px) elegidos por LOD. Nunca gradients en el loop.

⚡

6 efectos eléctricos

Rayos con midpoint displacement + ramas, centellas radiales, bolas de rayo globular, bobinas Tesla, chains Verlet y partículas clásicas.

🐦

Boids

Flocking Reynolds con spatial hash de 100 px. Cohesión, alineación y separación configurables. 3 presets listos (birds, fish, fireflies).

🔗

Verlet Chains

Cadenas físicas con N puntos, resolución iterativa de restricciones. Cuerdas, látigos y tentáculos listos para usar.

⬡

Rigid Bodies

Colisiones por impulso entre partículas con masa, restitución y spatial hash. Escombros, monedas, cristales.

💫

Trails & Metaballs

Estelas de polilínea con Float32Array ring buffers. Metaballs con blend aditivo para lava, agua y slime.

🌊

Curl & Flow

Curl noise barato (3 senos) para movimiento orgánico. Flow fields 32×32 con sampleo bilineal, regenerados cada 4s.

📉

LOD automático

3 niveles según partículas vivas: <3k = full, 3-6k = sin trails, >6k = physics cada 2 frames + sprites small.

🎯

Auto render scale

Cuando el FPS baja, reduce la resolución del canvas offscreen en 0.05. Cuando se recupera, la sube.

🧮

FAST_TRIG

Tablas precomputadas de sin/cos/tan/atan para mobile. 360-1800 entries, activable auto/on/off.

🪶

3 capas paralelas

Cada capa con su propio effectType, behavior y ~80 parámetros. Sliders en vivo, presets y multi-presets.

// API

Dos líneas y listo.

Sin npm install, sin build step, sin dependencias. Un <script> y un canvas.

index.html 
<!-- 1. Importá la librería -->
<script src="particle.js"></script>

<!-- 2. Tu canvas -->
<canvas id="game"></canvas>

<script>
  const lab = ParticleLab.create(canvas, {
    poolSize: 3000
  });
  lab.applyMultiPreset('storm');
  lab.start();
</script>
customize.js 
// Modificá capas en vivo
const L = lab.layers[0];
L.colors = ['magic', 'plasma'];
L.gravityY = 200;
L.swirl = 4;
L.blend = 'lighter';

// Spawn en coords de pantalla
canvas.addEventListener('pointerdown', e => {
  lab.spawnAt(e.clientX, e.clientY, 40);
});

// Slow-mo + bloom
lab.setTimeScale(0.3);
lab.setBloom(0.8);

// Escuchar frames
lab.onFrame = (dt) => {
  hud.textContent = lab.world.activeCount;
};
